AFTER A CONTROLLER IS MATCHED

The exact model carries its own controlled file set.

The selector is intended to lead directly from an interface requirement to the files required for schematic integration.

01Datasheet

Electrical limits, power, package, and supported functions.

02Fixed pinout

Pin number, direction, voltage domain, reset state, and connection.

03Reference schematic

Controller, transceiver, USB, protection, and recommended support circuits.

04Host protocol

Commands, frames, responses, errors, timeouts, and configuration behavior.

05Software tools

Windows and Linux test tools, examples, and verification procedure.

06Revision record

Product revision, validation status, changes, and known limitations.
