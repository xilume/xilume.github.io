PRODUCT PRINCIPLE

One orderable model defines one complete behavior.

The controller is not sold as a general development MCU. The application firmware is supplied by XILUME and the customer designs around a documented, stable interface.

FIXED

Application firmware

Communication handling, buffering, status logic, and host protocol are programmed before shipment.

FIXED

Functional pinout

Every orderable model has a controlled pin definition for power, host, field interfaces, and status signals.

SELECTABLE

Operating settings

Supported bus speeds and normal operating options are selected through the documented host protocol.

EXTERNAL

Physical-layer design

Transceivers, isolation, termination, connectors, and protection follow the reference schematic and system needs.
