  2. Check power, clock and package

Separate serial and CAN FD access

Host protocol and validation requirements

The current host protocol supports Classical CAN and CAN FD data frames with BRS. RTR remote frames are not represented; extended frames with numeric IDs at or below 0x7FF cannot be distinguished from standard frames, and ESI is not encoded in the receive format. Check these requirements before design-in.
