协议能力核对

当前协议支持经典 CAN 与 CAN FD 数据帧及 BRS；RTR 远程帧不表示，数值不高于 0x7FF 的扩展帧无法与标准帧区分，接收格式不编码 ESI。各通道共享 USB 全速链路，实际总吞吐量应按目标工作负载验证

设计检查

  1. 核对器件和引脚方向

    按对应器件的顶视引脚图核对封装方向，再检查电源、保留引脚偏置和 NC 引脚处理

  2. 核对时钟与收发器

    两款数据手册规定主时钟为 8.000 MHz；按各通道的速率与电压要求选择外部收发器

  3. 核对布局与封装

    按数据手册检查 USB 差分布线、去耦和参考地；封装机械图用于几何核对，PCB 焊盘与钢网按装配工艺确认

  4. 完成整机验证

    检查多通道并发、USB 重新连接、主机重启与电源恢复，并按应用要求验证温度、干扰和总线终端配置
