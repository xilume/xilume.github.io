INTERNAL DUAL CAN FD INTERFACE

Put two CAN FD channels inside the embedded computer.

WHY INTERNAL

Keep the CAN interface inside the system.

External adapters consume ports, add loose cables, and complicate enclosure design. An internal module creates a cleaner, more repeatable integration path.
01

Internal installation

Keep the interface secured inside the embedded computer instead of adding another external enclosure.

02

Two CAN networks

Connect two independent CAN or CAN FD buses from one internal module.

03

Cleaner system integration

Reserve external USB ports and reduce loose adapter hardware around the finished system.

SYSTEM VIEW

From the host slot to two separate field networks.

The module receives USB signals from a compatible Mini PCIe slot and exposes two CAN paths to the external equipment.
  • Embedded PC or industrial computer
  • Compatible full-size Mini PCIe slot
  • USB 2.0 signals supplied in the slot
  • CAN / CAN FD network A and network B
COMPATIBILITY CHECK

Mini PCIe connector does not mean PCIe data.

This module uses USB 2.0 signals in the Mini PCIe slot and does not use PCIe data lanes. Confirm that the host slot exposes compatible USB signals before design-in.

BEFORE YOU BUY

Verify the slot, signal route, and external connector plan.

The mechanical connector alone is not enough to guarantee compatibility. The host schematic or manufacturer documentation must confirm the USB connection.
  • Full-size card space is available
  • Slot provides compatible USB 2.0 signals
  • External CAN connector or harness is planned
  • Power budget and mounting are confirmed
