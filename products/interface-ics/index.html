Production · mixed-interface IC

XL1326

6 serial + 2 CAN FD channels

XL1326 provides two CAN FD controller channels and six serial controller channels over USB. With the Xilume Windows driver, all eight channels enumerate as named COM ports. Serial endpoints use standard serial applications; CAN FD endpoints use the Xilume CAN FD protocol. External bus transceivers are required.

XL1326-A

2 CAN FD controller channels

XL1326-A provides two CAN FD controller channels over USB in an LQFP48 package. With the Xilume Windows driver, the channels enumerate as two named COM endpoints for the Xilume CAN FD protocol. One external CAN FD transceiver is required per channel.
