界面功能

设备连接

选择 Xilume CAN FD 端口并建立连接，软件会识别当前 CAN 通道

报文发送

选择经典 CAN 或 CAN FD，设置 BRS、CAN ID、数据长度与 DATA，支持单次和周期发送

实时数据

按时间显示 RX 与 TX 帧，包括方向、类型、CAN ID、DLC、DATA 与原始内容

筛选与导出

可仅显示 RX 或 TX，按 CAN ID 过滤，复制选中内容并保存为 CSV

位时序与状态

使用预设或自定义仲裁段与数据段参数，读取当前硬件位速率和通道状态

双通道同时使用

每个窗口连接一个 CAN 通道，需要同时操作 CANFD1 与 CANFD2 时可打开两个窗口

适用产品 双路 Mini PCIe CAN FD、Octant、XE826、XL1326、XL1326-A
