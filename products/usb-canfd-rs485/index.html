External circuitry for the controller version

The customer PCB requires two CAN FD transceivers and two RS-485 transceivers, plus power, protection, direction-control, USB, clocking, and the documented support components.

USB bandwidth

USB Full-Speed is the shared host connection. Sustained simultaneous traffic will be validated before final specifications.

RS-485 configuration

Each channel is planned to support independent baud rate, data bits, parity, stop bits, and direction control.

Host formats

The USB version connects directly. The Mini PCIe version uses USB 2.0 signals supplied by a compatible Mini PCIe slot.
