Interface overview

Device connection

Select a Xilume CAN FD COM port, connect, and let the application identify the active CAN channel.

Frame transmission

Choose Classical CAN or CAN FD, then set BRS, CAN ID, length, and data for one-time or cyclic transmission.

Live traffic

View timestamped RX and TX frames with direction, type, CAN ID, DLC, data, and raw content.

Filtering and export

Show RX or TX traffic, filter by CAN ID, copy selected rows, and save the traffic log as CSV.

Bit timing and status

Use presets or custom nominal and data-phase settings, then read the active hardware rate and channel status.

Using two channels

Each window controls one CAN channel. Open a second instance when CANFD1 and CANFD2 are needed at the same time.

Compatible products Dual Mini PCIe CAN FD, Xilume Octant, Xilume XE826, XL1326, and XL1326-A
