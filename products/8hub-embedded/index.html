Interface architecture

One host connection. Three bus types. Eight named channels.

The standard configuration replaces a collection of external adapters with one internal board and a single USB link to the host.

Native OS integration + official software

The integration stack ships with the hardware.

Windows shows eight named Xilume devices in Device Manager. Linux is supported with two SocketCAN interfaces and six tty serial devices. Drivers, tools, SDKs, examples, and documentation complete the path from enumeration to application code.
