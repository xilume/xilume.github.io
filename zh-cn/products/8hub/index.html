到现场诊断

设备、总线和项目阶段不断变化，电脑端的工作方式无需改变。

01 · 机器人与 AGV

机器人 / AGV 研发联调

CAN FD 接 BMS 或底盘，RS-485 接传感器与驱动器，RS-232 接配置口，由一台电脑同时管理。

CAN FD → BMS / 底盘RS-485 → 传感器 / 驱动器RS-232 → 配置口
02 · 验证测试

自动化测试台

同时连接多块控制板、驱动器或仪表，再由主机软件自动完成收发、记录与报告流程。

多设备并行通信记录主机自动化
03 · 现场维护

现场维修诊断

工程师携带笔记本到现场，读取故障、修改参数并检查通信。

04 · 接口扩展

工控机接口扩展

无需更换主板，为缺少串口与 CAN 的 Windows 或 Linux 工控机增加工业接口。

高校实验室
